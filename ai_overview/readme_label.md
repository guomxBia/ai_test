# AI Data Labeling Tools

Quick picks based on your use case:

- **General-purpose & free** → [Label Studio](https://labelstud.io/)
- **Easiest for images** → [Roboflow](https://roboflow.com/)
- **Quick, no install, small dataset** → [makesense.ai](https://www.makesense.ai/)

## Reference: More Options

| Tool | Best For | Notes | License |
|---|---|---|---|
| **CVAT** | Images & video, object detection | Industry standard for video/image annotation; AI-assisted labeling (auto object tracking); more "power user" feel than Roboflow | Free / open-source |
| **Labelbox** | Professional/enterprise AI datasets | Strong UI & collaboration features; free tier more limited than Label Studio | Paid / limited free tier |
| **Prodigy** | NLP/text (NER, classification) | Favorite among ML practitioners | Paid (one-time license) |
| **Doccano** | Text & NLP (NER, sentiment) | Simple, web-based, easy to set up for NLP tasks | Free / open-source |
| **Labelme** | Simple image annotation | Lightweight classic desktop app (Python); great for quick, local polygon annotation without complex setup | Open-source (MIT) |
